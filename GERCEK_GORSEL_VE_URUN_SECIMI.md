# Gerçek eklenti görüntüleri ve günlük ürün seçimi

Bu sürüm için güncel adımlar [README.md](README.md) içinde açıklanmıştır. WinProducts API zorunlu değildir. Ücretli veritabanı erişimini varsaymayız. Chrome Web Store'dan uzantıyı doğrudan indirmek için `npm run extension:install` komutu eklendi; masaüstü Chrome kurulumunda kurulu uzantı da saptanabilir; ilk oturum etkileşimli yürütülür.

**Önemli:** WinProducts eklentisi otomasyon ortamında kurulu/oturum açık değilse gerçek ekran yakalanamaz. Görsel doğrulanmadıkça tweet yayımlanmaz. Ürün seçimi, kaydedilmiş ve doğrulanmış aday havuzundaki ölçülebilen güncellik ve tekrar kurallarına dayanır; doğrulanmamış verilerle ürün başarısı iddiası üretilmez.
