# Güvenlik notları

Bu repo PUBLIC kalabilir; fakat hiçbir kimlik bilgisi veya kullanıcı oturumu depoya koyulmamalıdır.

- Asla `.env`, `.browser-profile/`, `.extensions/`, Chrome cookies/storage veya X OAuth token commit etmeyin.
- Gerçek anahtarları `Settings > Secrets and variables > Actions > Secrets` alanına ekleyin.
- WinProducts paneli gerçek ekran görüntülerini paylaşmadan önce özel bilgileri ve yayınlama izinlerini kontrol edin.
- Otomatik yayın ancak `AUTOMATION_ARMED=true`, `PUBLISH_ENABLED=true`, gerçek WinProducts görüntü onayı ve X API kimlikleri tamamlandıktan sonra etkinleştirilmelidir.
